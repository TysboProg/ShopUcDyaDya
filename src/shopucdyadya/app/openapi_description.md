## О проекте

**Магазин дядюшки** — сервис для быстрой покупки UC (Unknown Cash) для PUBG Mobile.

### Возможности
- 💰 Покупка UC любого номинала
- 💳 Оплата через популярные платёжные системы
- 🤖 Автоматическая выдача промокода через Telegram-бота
- 🛟 Поддержка 24/7

### Как это работает
1. Пользователь выбирает пакет UC
2. Оплачивает заказ
3. Получает промокод в Telegram-боте для активации в игре
